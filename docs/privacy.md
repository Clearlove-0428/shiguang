# 数据说明

聊天记录读取、规则分析、模型推理和日程存储在本机进行。连接本机账号时，程序会只读检查已登录客户端和用户选定的数据目录；取得的访问材料通过 Windows DPAPI 保存在本机数据目录。请只读取自己有权访问的账号。

公开网页订阅需要联网。开发启动的手机桥接默认只监听本机；主动改为局域网监听并完成配对后，才与手机客户端交换数据。源码包未包含配对码、访问密钥、账号信息或私人数据库。

运行记录、缓存和日程保存在 `.local/data`。删除数据前请自行备份；提交问题时使用自己编造的通知和账号目录复现，不要提交原始聊天、账号库、DPAPI 文件、截图中的个人信息或录音。

源码检查用于发现常见凭据、私人路径和误入仓库的文件，不代表已经证明所有内容都没有个人信息。发布前仍要审阅实际文件清单和新增样例。
