# 这次源码的范围

本目录来自正式版 0.15.2-beta.2，包含 Windows 核心模块、前端、Windows 平台脚本、C# 原生窗口源码和测试。

与个人安装目录相比，源码目录做了这些调整：

1. 开发默认端口改为 43527、43528、43529，`npm start` 将数据放在 `.local/data`，避免与现有个人版相混。
2. 首次启动保留蓝色主题，使用规则初筛，桌宠和托盘默认关闭。用户在源码版里保存的设置继续持久化。
3. 只提供拾笺、汐白、墨璃三位原创角色图片；不附带五条悟、初音、Live2D 模型和 SDK。资源清单为空时跳过相应资源测试，偏好与接口测试继续保留。
4. 将原来依赖工程外目录的三个浏览器检查与提醒窗口检查移到 `test/helpers/`；增加显式的浏览器和 Windows 原生测试入口。
5. 缺失的可选静态文件返回 404，避免服务读取不存在的图片时退出；设置页不显示未安装的五条悟卡片。
6. 开发启动使用安装好的 Node.js，可选原生窗口从源码构建。旧版安装器、便携运行时和私人验收文件不在源码目录里。
7. 修正蓝色主题中过期事项的标题与日期颜色，保证深蓝卡片上的文字对比度。原接入浏览器回归中的过期通知会实际检查这一点。
8. 新建源码版数据时，旧读取配置迁移到新接入模块后仍保持暂停，需主动选择账号并开始读取；已有配置继续保留。

核心解析、日期校验、会话读取、日程存储、提醒与同步逻辑沿用正式版。Android、iOS 的客户端源码不在这次 Windows 核心目录中。
