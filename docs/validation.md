## 自己复现

```powershell
npm ci --ignore-scripts
npm test
npm run check:source
```

浏览器和Windows原生检查需额外准备组件，再分别运行 `npm run test:ui` 与 `npm run test:native`。具体步骤见[开发说明](development.md)。跳过项会列在输出中。

测试使用合成通知、临时数据库和模拟账号目录。截图也来自合成通知的实际界面，未把私人聊天作为公开样例。
