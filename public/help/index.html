先用一条通知走通流程

源码版首次使用规则初筛，不需要下载模型。先粘贴一条自己编造的通知，核对后再连接真实账号。

  1. 打开顶部“微信 / QQ 接入”，点“粘贴通知 / 文字 PDF”。
  2. 填写来源和原始发送时间，粘贴通知，解析方式选择“规则初筛”。
  3. 去“待确认”核对日期、时间与原文；手动导入的通知可在来源筛选中选“全部来源”。
  4. 点“确认安排”，再去“近期日程”查看。
  5. 需要 Windows 提醒时，在本地设置检查提醒开关，并保持电脑和源码服务运行。

连接自己的微信或 QQ

在接入页检查本机目录，选择自己的账号，再主动开始读取。客户端版本变化可能导致读取失败；请看真实状态和错误信息。不要向别人提供密码、聊天库或密钥文件。

开发与可选组件

源码默认端口为 43527，开发数据在 .local/data。模型、WebView2 原生窗口构建和浏览器测试见仓库的 README 与 docs/development.md。源码不包含五条悟、初音或 Live2D 素材。
